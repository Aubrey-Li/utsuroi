# Fonts

## EMS Allure (`EMSAllure.svg`)

A single-line ("stroke") version of the Allura script, used to write typed
text into the sand stroke by stroke.

- Allura designed by Rob Leuschke, TypeSETit. Copyright 2010 The Allura Project Authors.
- Single-line version created by Sheldon B. Michaels; SVG font conversion by Windell H. Oskay (Evil Mad Scientist).
- Source: the Inkscape extensions repository (`svg_fonts/EMSAllure.svg`).
- License: SIL Open Font License 1.1, see [`OFL.txt`](OFL.txt).

`src/strokes/fonts/ems-allure.json` is generated from this file with
`npm run fonts` and is distributed under the same license.
